# Responsive design

- Design from content and layout constraints, not device names alone.
- Check at least narrow, medium, and wide viewports when tools permit.
- Prefer fluid sizing, flexbox/grid, intrinsic layout, and content-aware breakpoints.
- Prevent horizontal overflow and clipped essential content.
- Ensure navigation, tables, forms, dialogs, charts, and media remain usable on narrow screens.
- Reconsider hierarchy and density on mobile rather than simply shrinking desktop layout.
- Verify touch interactions and focus states.
- Test long headings, translated strings, empty states, error states, and unusual data.
- Avoid fixed heights for content containers unless required by the interaction.
- Report which viewports were actually checked and with what method.
