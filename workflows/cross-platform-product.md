# Workflow: cross-platform product

1. Establish which surfaces are required: web, iOS, Android, tablet, or some subset.
2. Define shared product goals, user journeys, information architecture, content, and semantic design tokens.
3. Inspect each target repository and stack independently; do not assume identical architecture.
4. Propose one coherent visual system with platform-aware implementations and explain important deviations.
5. Obtain approval for major direction and scope.
6. Implement platform-native patterns while preserving shared brand and product intent.
7. Verify each platform with the tools available for that platform; separate tested platforms from untested ones.
8. Deliver a cross-platform consistency summary and a list of platform-specific differences and checks.
