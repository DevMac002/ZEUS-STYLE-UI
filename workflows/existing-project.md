# Workflow: existing project

1. Inspect relevant files, framework, styling, design tokens, routes, components, and tests.
2. Understand the requested outcome and existing behavior to preserve.
3. Identify the smallest safe change that can deliver the outcome.
4. If the request implies a major design or architecture decision, present options and ask for approval.
5. Implement using project conventions; avoid unrelated rewrites and new dependencies.
6. Run the most relevant tests and checks available.
7. Summarize modifications and distinguish verified outcomes from assumptions.
