# Workflow: component-only task

1. Inspect the target component, its callers, styling conventions, props/types, and related tests.
2. Confirm intended behavior and visual goal from the request; avoid broad discovery.
3. Reuse existing tokens and patterns.
4. Make the smallest complete change; include relevant responsive and interactive states.
5. Run component tests, lint/type checks, or build steps that are practical.
6. Report the change and any checks not run.
